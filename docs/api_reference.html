Overview

MLPipelineHolder is a lightweight Python library for building, running, tracking, and modifying experiment-driven machine-learning pipelines, particularly in Jupyter and Google Colab notebooks. It organises workflows into explicit execution blocks and nested child pipelines while keeping their runtime structure easy to inspect and modify.

The package exposes its public API from the top-level mlpipelineholder package. Every name listed in the index is importable directly:

Import the public API
from mlpipelineholder import (
    PipelineHandler,
    ExecutionBlock,
    GateBlock,
    PipelineLogger,
    ExecutionError,
    PersistenceError,
    PipelineError,
    RegistrationError,
    ResolutionError,
    rename_args,
)

PipelineHandler

PipelineHandler

The central class that owns configuration, values, child pipelines, execution, save/load, and logging. Construct one per pipeline scope, then attach blocks and child pipelines.

class mlpipelineholder.PipelineHandler( registration_name: str, configuration: Any | None = None, local_folder_path: str | Path | None = None, execution_priority: float | None = None, forced: bool = False, memory_saving_mode: bool = False, memory_profile_logging: bool = False, pipeline_backup_directory: str | Path | None = None, log_traceback_to_file: bool = True, show_traceback_locals: bool = False, use_rich_traceback_console: bool = True, torch_load_weights_only: bool = False ) -> None
Parameters

execution_priorityfloat | NoneOptional priority used when this pipeline is a child node of a parent.

add_block()

add_block(registration_name: str, execution_priority: float, forced: bool = False) -> ExecutionBlock

Registers a new execution block on this pipeline and returns it. Blocks run in ascending priority order; functions registered inside the same block run in parallel.

add_child_pipeline()

add_child_pipeline(child_pipeline: PipelineHandler, execution_priority: float, registration_name: str | None = None, forced: bool = False) -> PipelineHandler

Attaches an existing PipelineHandler as a child node of this pipeline at the given priority. The child is relocated under this pipeline's project tree.

Raises RegistrationError if the child's declared output names conflict with visible configuration fields or pipeline constants anywhere in the tree.

Builds and attaches a single-function child pipeline around target_function, wiring gate configuration, parameter mapping, positional and keyword arguments, and disk-backed outputs in one call.

run_all()

run_all(overrides: dict[str, Any] | None = None) -> RunRecord

Executes every node in the pipeline tree in ascending priority order. Returns a RunRecord summarising the run.

run_until()

run_until(*path_parts: str, overrides: dict[str, Any] | None = None) -> RunRecord

Executes all nodes with priority lower than the target node's priority. Supports nested paths, for example run_until("modeling_pipeline", "predictor_components").

run_from()

run_from(*path_parts: str, overrides: dict[str, Any] | None = None) -> RunRecord

Executes the target node and everything after it. Supports nested paths, for example run_from("modeling_pipeline", "predictor_training_pipeline").

run_block()

run_block(*path_parts: str, overrides: dict[str, Any] | None = None) -> RunRecord

Executes only the target block or child pipeline at the given path.

get_value()

get_value(variable_name: str) -> Any

Returns a produced value visible to this pipeline (own outputs, upstream parent outputs, or descendant values). If the value is disk-backed, the true object is loaded and returned.

Raises ResolutionError for unknown names, and for names that are pipeline constants (use get_constant_value() instead).

get_constant_value()

get_constant_value(variable_name: str) -> Any

Returns a pipeline constant set via set_constant_value(), resolving the nearest definition in the visibility chain: own constant, then earlier-priority sibling, then parent, then grandparent. Disk-backed values are loaded from disk.

Raises ResolutionError if no such constant exists.

set_constant_value()

set_constant_value(variable_name: str, value: Any) -> None

Creates or replaces a pipeline constant. The constant is visible to this pipeline, its descendants, and downstream siblings through the parent visibility model.

Raises RegistrationError if the name is a declared output or an existing produced value anywhere in the pipeline tree, and for reserved builtin names.

Example
pipeline.set_constant_value("learning_rate", 0.01)
rate = pipeline.get_constant_value("learning_rate")

set_value()

set_value(variable_name: str, value: Any) -> None

Updates an existing produced value, or injects a value for a declared-but-cleared produced name (a name declared as an output by a block that has not produced it yet).

Raises ResolutionError for unknown names and for names owned by pipeline constants (use set_constant_value() instead).

update_value()

update_value(variable_name: str, value: Any) -> None

Updates an existing produced value only. Raises ResolutionError for unknown names and for names owned by pipeline constants (use set_constant_value() instead).

set_config()

set_config(overrides: dict[str, Any]) -> None

Adds new configuration fields or updates existing ones. Writes that would conflict with declared output names are rejected.

update_config()

update_config(overrides: dict[str, Any]) -> None

Updates existing configuration fields only. Unknown fields are ignored or rejected depending on the method; see the class notes.

get_config_value()

get_config_value(field_name: str) -> Any

Returns a single configuration value visible to this pipeline, including inherited parent config values. Raises ResolutionError if the key does not exist.

get_full_config()

get_full_config() -> dict[str, Any]

Returns the visible merged configuration for this pipeline, including parent configs recursively. The current pipeline's config overrides same-named parent values.

config_as_dict()

config_as_dict() -> dict[str, Any]

Returns the local configuration as a plain dictionary (without parent inheritance).

save_pipeline()

save_pipeline(path: str | Path | None = None, save_log_to_file: str | Path | None = None) -> Path

Saves the pipeline project tree. Without path, saves to the current project_root. Passing a different path creates a restart-safe copy of the current project tree (including nested children and disk-backed artifacts) before writing fresh state. The target must not overlap the current project tree.

When a pipeline_backup_directory is configured, an in-place save also refreshes the backup copy.

Every call also archives a timestamped copy of the current pipeline.log into history_logs/ inside the project root (e.g. history_logs/2026-08-18_16-38-14.857.log, UTC, yyyy-mm-dd_hh-mm-ss.mmm), preserving the save-time log snapshot even though loading a pipeline starts a fresh pipeline.log.

When a pipeline_backup_directory is configured, the refreshed backup copy also receives the updated history_logs/ folder. Loading a saved project restores its history_logs/ folder into the project root, so previously archived snapshots remain available after a load.

save_project()

save_project(path: str | Path | None = None, save_log_to_file: str | Path | None = None) -> Path

Compatibility alias for save_pipeline().

load_pipeline()

@classmethod load_pipeline(path: str | Path, *, forced_deleting: bool = False) -> PipelineHandler

Loads a saved pipeline project. Reads lightweight metadata before loading full state. If path differs from the canonical working directory, the saved tree is restored to the canonical directory before loading.

  • forced_deleting=False asks for keyboard confirmation before deleting a non-empty canonical working directory.
  • forced_deleting=True deletes the canonical working directory directly.

Missing runtime callables raise during loading instead of being passed to stages as inert placeholders.

load_project()

@classmethod load_project(path: str | Path, *, forced_deleting: bool = False) -> PipelineHandler

Compatibility alias for load_pipeline().

recover_variable_from_backup()

recover_variable_from_backup(name: str) -> None

Restores one current value from the latest complete in-place backup. Call on the root pipeline only. Updates in place and returns None.

  • If the same name is independently owned by multiple pipelines, one prompt lists every affected pipeline; only yes/y applies the recovery to all of them.
  • Disk-backed values are copied into the live project so they remain usable if the backup is later removed.
  • Requires pipeline_state.pkl, config.pkl, and pipeline_meta.pkl plus every saved artifact referenced by the backup.
  • Does not rerun or invalidate derived outputs.

recover_config_from_backup()

recover_config_from_backup(name: str) -> None

Restores one config field from the latest complete in-place backup. Call on the pipeline that locally owns the field. Descendants inherit the restored field through normal config visibility unless they define their own local override. Returns None.

__str__() / __repr__()

__str__() -> str     __repr__() -> str

Both render the pipeline chart produced by describe_pipeline(), so print(pipeline) and repr(pipeline) are readable.

Example: build, run, and inspect
from mlpipelineholder import PipelineHandler

def produce_seed(base: int) -> int:
    return base + 1

pipeline = PipelineHandler("demo", {"base": 2}, local_folder_path="/tmp/demo_run")
setup = pipeline.add_block("setup", 1)
setup.register_function(produce_seed, ["seed"])

pipeline.set_constant_value("learning_rate", 0.01)
pipeline.run_all()

print(pipeline.get_value("seed"))          # 3
print(pipeline.get_constant_value("learning_rate"))  # 0.01
print(pipeline.describe_pipeline())

ExecutionBlock

class mlpipelineholder.ExecutionBlock( parent: PipelineHandler, registration_name: str, execution_priority: float ) -> None

register_function()

register_function( function_or_path: Any, output_variable_names: str | list[str] | tuple[str, ...] | None, save_to_disk: list[str] | tuple[str, ...] | set[str] | None = None, param_mapping: dict[str, str | None] | None = None, var_pos_name: str | None = None, var_kw_name: str | None = None, forced: bool = False ) -> FunctionRegistration | None

Registers a function in this block. Inputs are resolved at execution time from explicit overrides, para_value_dict, config fields, and function defaults, in that order.

  • Returns the created FunctionRegistration, or None when the registration was rejected (for example duplicate output names, output names conflicting with visible configuration fields or pipeline constants, or builtin names).
  • param_mapping exposes safer pipeline-facing parameter names without changing the callable.
  • var_pos_name / var_kw_name map variadic *args / **kwargs to named pipeline inputs.
  • save_to_disk names must be a subset of output_variable_names.
Example
block.register_function(
    multiply,
    ["result"],
    param_mapping={"seed": "seed", "factor": "factor"},
)
block.register_function(
    mapped_variadic,
    ["result"],
    param_mapping={"obj": "payload", "scale": "scale_value"},
    var_pos_name="extra_args",
    var_kw_name="extra_kwargs",
)

register_expression()

register_expression( code: str, *, output_variable_name: str | None = None, save_to_disk: bool = False, forced: bool = False, warn_on_input_mutation: bool = False ) -> ExpressionRegistration

Registers a single-statement expression. Must be an assignment (NAME = EXPR) or a print/logger call. No semicolons, imports, eval/exec/__import__, comprehensions, walrus operators, or nested definitions.

  • Returns None when the registration is rejected (for example output name conflicts).
  • Imports used by expressions are supplied through define_expression_runtime().

Exceptions

PipelineError

class mlpipelineholder.PipelineError(Exception)

Base class for all pipeline-specific errors. Inherits from Exception.

RegistrationError

class mlpipelineholder.RegistrationError(PipelineError)

Raised when a block, function, child pipeline, configuration field, or constant name cannot be registered: duplicate names, builtin names, output-name conflicts with visible configuration fields, or output-name conflicts with pipeline constants.

ResolutionError

class mlpipelineholder.ResolutionError(PipelineError)

Raised when a value, constant, or configuration field cannot be resolved: unknown names, missing configuration keys, or using get_value()/update_value()/set_value() on a pipeline constant.

ExecutionError

class mlpipelineholder.ExecutionError(PipelineError)

Raised when pipeline execution fails (for example an unresolvable function argument or a same-block dependency that cannot run in parallel).

PersistenceError

class mlpipelineholder.PersistenceError(PipelineError)

Raised when save, load, or backup recovery fails: missing artifacts, unsafe paths, aborted directory restores, invalid or incomplete backup data, or unresolved callable placeholders.
